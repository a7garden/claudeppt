# 제안: 다른 PC 에서 링크로 들어와 「담당」 단위로 함께 고치기

## 하고 싶은 것

0.5.0 의 「담당」이 같은 PC 의 Claude Code 세션 여럿이 덱을 나눠 고치게 해 주었는데, 이것을 **다른 PC 사람까지** 넓히고 싶습니다.

- 호스트 PC 의 ClaudePPT 가 서버가 되고, 다른 사람은 **초대 링크로 브라우저에서** 들어옵니다(설치 없음, 사무실 안 · 밖 같은 링크).
- 담당마다 **앱이 직접 돌리는 Claude 세션**을 두고, 그 담당에 권한이 있는 사람들이 거기에 명령합니다. 누가 명령해도 같은 세션에 이어져 맥락이 남고, 턴 · 판마다 **누가 시켰는지** 남습니다.
- 핀 · 표시를 작성자 · 상태가 있는 의견으로 넓혀, 검토자의 의견을 그 쪽 담당 세션으로 보냅니다.

## 원본 구조를 어떻게 쓰나

- 담당 정의 · presence · activity · 경로 단위 판 · 권한(theme · order · manage)은 **그대로** 씁니다. `seats.json` 에는 앱 세션 id 칸 하나(`appSession`)만 더하려 합니다.
- 바깥 Claude Code 세션이 맡은 담당은 지금처럼 그 세션 몫이고, 앱 세션은 비어 있는 담당만 맡습니다.
- 원격 요청은 지금의 바깥 CLI 명령 처리기(판 남기기 · 쪽 손보기 · 하는 일 · 핀)를 그대로 거치게 하고, 앞에 「사람 → 담당」 권한 검사만 둡니다.
- 앱이 띄우는 세션이라 `--settings` 권한 규칙으로 맡지 않은 파일 고치기를 미리 막을 수 있습니다(판에서 걸러내는 지금 장치는 두 번째 그물로 둡니다).
- 모든 협업 기능은 「설정 › 협업」 스위치 뒤(기본 꺼짐)에 둡니다 — 켜기 전에는 바뀌는 것이 없습니다.

## 나눠 낼 순서

| 단계 | 담는 것 |
| - | - |
| M1 같이 보기 | 전송층 분리(`api.ts`) · 호스트 HTTP/WebSocket 서버(axum, 기본 꺼짐) · 브라우저 보기 · 누가 어디 보는지 · 원격 대역폭(캐시 · 썸네일 PNG · 글꼴 나눠 받기) |
| M2 초대 · 사람 · 의견 | 초대 링크 · 역할 · 사람-담당 잇기 · 공유 의견 · 바깥 길(Tailscale Funnel / Cloudflare Tunnel) |
| M3 앱 담당 세션 | 담당마다 앱 세션(`--session-id` 고정) · 요청자 기록 · 대기열 · 미리 막는 쓰기 범위 |

각 단계 안에서도 작은 PR 로 나누겠습니다. 시작 전에 기술 검증 실험(터널 WebSocket · `--settings` 권한 규칙 · 세션 기록 옮기기 등)을 먼저 하고 결과를 이 이슈에 남기겠습니다.

설계 문서: https://github.com/eunchaipark/claudeppt/blob/plan/collab/.taskmaster/docs/collab-architecture.md

2. `seats.json` 에 칸을 더하는 것, 앱 세션을 `presence.json` 에 `"app:<uuid>"` 로 적는 것이 괜찮을까요? 다른 방식을 원하시면 따르겠습니다.
3. 호스트 서버를 앱 안(axum)에 두는 것과 CLI 서브명령(`claudeppt.exe serve`)으로 두는 것 중 선호하시는 쪽이 있을까요?
4. 원본이 빠르게 바뀌어서, PR 크기 · 주기에 대한 바람이 있으면 알려 주세요.
