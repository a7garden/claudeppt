# ClaudePPT 여러 PC 협업 — 설계안

2026-11-25 · **원본 0.6.0 기준**(a7garden/claudeppt `1b4883e`) · Task Master 태그 `master`(안정화 · 최적화) · `collab`(협업)
진행 방식: fork(`eunchaipark/claudeppt`)의 작은 브랜치 → 원본으로 PR. 판 번호는 원본 관리자가 정하므로 이 문서는 마일스톤(M0~M4)으로 적는다.

## 0. 한 줄 요약

원본 0.5.0 의 **「담당」(seats)** 을 그대로 협업의 단위로 쓴다. 지금은 같은 PC 의 바깥 Claude Code 세션만 담당을 맡는데,
여기에 **앱이 직접 돌리는 담당 세션**을 더하고, 다른 PC 사람들은 **줌처럼 링크 하나로 브라우저에서** 들어와 그 세션에 명령한다.
턴마다 **누가 시켰는지** 남고, 쓰기는 호스트 한 곳에서만 일어난다.

## 3. 근거 — 확인한 사실

| 사실 | 근거 |
| - | - |
| 화면 → Rust 길은 `api.ts` 한 곳. 슬라이드 제공 `serve()` 는 경로 검사를 포함한 독립 함수 | `api.ts`, `lib.rs` |

### 4.1 담당을 맡는 것이 둘이 된다

| | 바깥 Claude Code 세션 (원본) | 앱 담당 세션 (새로) |
| - | - | - |
| 누가 띄우나 | 사용자가 터미널에서 | 앱이 담당마다 |
| 누가 명령하나 | 그 터미널의 사용자 | 그 담당에 명령 권한이 있는 사람들 (로컬 · 원격) |
| 세션 id | Claude Code 가 정함 (`CLAUDE_CODE_SESSION_ID`) | 앱이 정함 (`--session-id`, `seats.json` 에 적음) |
| presence | CLI join 이 적음 | 앱이 적음 (`session: "app:<uuid>"`, 턴마다 seen · doing) |
| 범위 | 판에서 걸러냄 | 판에서 걸러냄 + `--settings` 권한 규칙으로 **미리 막음** |
| 둘이 겹치면 | — | 바깥 세션이 맡은(신선한) 담당엔 앱 세션이 턴을 돌리지 않고 「바깥 세션이 맡음」 표시. 편집장이 「비우기」 후 넘김 |

### 4.2 쓰기는 한 곳에서

- **의도 API = 바깥 CLI 명령 + 몇 가지.** 원본이 이미 담당 권한을 검사하며 처리하는 명령(판 남기기 · 쪽 더하기/빼기/옮기기 · 하는 일 · 핀)이 있다. 원격 화면의 의도를 같은 처리기로 보낸다. 더할 것: `turn.send(seat, text, refs)` · `direct.edit(slide, patch)` · `pin.add/update/resolve`(작성자 · 상태) · `member.*`.
- **처리기 위치**: M2 는 원본 방식 그대로(`control.rs → remote.ts`, 호스트 화면의 TS) + 덱별 직렬 큐. M3 에서 그리기가 필요 없는 것(파일 · git · 세션 · 의견)을 Rust 코어로 옮긴다. 의도 꼴이 같으므로 원격 화면은 바뀌지 않는다.
- **CRDT 는 쓰지 않는다.** 쪽 파일은 그 담당만 고치고, 순서 · 의견은 코어가 한 줄로 세운다.

### 4.3 사건과 재접속

- 덱 단위 일련번호(seq): `fs.changed` · `turn.delta{seat, turn}` · `turn.state` · `queue{seat}` · `seat.*`(seats · presence · activity) · `presence.view{member, slide}` · `pin.*` · `version.new{n, seat, author}`.
- 재접속 때 마지막 seq → 놓친 사건 다시 보내기(짧은 고리 버퍼) 또는 「전체 다시 읽기」.
- 전송은 WebSocket(SSE 쓰지 않음 — quick tunnel 미지원), 막히면 긴 폴링. 턴 글자 조각은 30ms 묶음.
- 원본 `store.ts` 는 담당 파일을 8초마다 다시 읽는다 — 원격에선 사건으로 바꾼다.

### 4.4 앱 담당 세션

| 항목 | 정한 것 |
| - | - |
| 세션 id | 담당을 만들 때 UUID → `seats.json` 의 그 담당에 `appSession` 으로. 첫 턴 `--session-id`, 이후 `--resume` |
| 세션 기록 보존 | 턴이 끝날 때 `~/.claude/projects/<폴더>/<id>.jsonl` 을 `.claudeppt/sessions/<id>.jsonl` 로 복사, 덱을 열 때 없으면 되돌림 (master 의 세션 복구와 같은 장치) |
| 대기열 | 한 담당은 한 번에 한 턴, 다른 담당끼리 동시. 호스트 전체 동시 상한(기본 3) |
| 요청자 | 턴 요청문 첫 줄 `[요청자: B · C 의견 #12 반영]`, 턴 기록 · 판 작성자 · activity 에 같이 |
| 쓰기 범위 | 시스템 프롬프트에 `seats::rules` 글 + `--settings` 권한 규칙(`seats::allows` 로 계산한 파일만 Edit · Write) + 판에서 걸러냄(원본) |
| 캐시 | 시스템 프롬프트는 담당마다 고정. 쪽 수 · 파일 목록 · 요청자는 턴 요청문으로 |
| 모델 | 담당 세션 `sonnet` · effort `medium`, 모든 권한 담당(편집장) `opus`, 잔일 `haiku` · `low`. 담당마다 바꿀 수 있게 |
| 인증 | 요청한 사람의 인증(setup-token 장기 토큰 또는 API 키)을 그 턴 프로세스 env 로. `CLAUDE_CONFIG_DIR` 은 바꾸지 않는다(세션 기록이 갈라짐) — 실험으로 확인 |
| 앱 안 Claude(기존 대화) | 담당이 없을 때는 원본 그대로. 담당이 있으면 「모든 권한 담당」의 앱 세션으로 본다 |

### 4.5 사람과 담당 잇기

- 사람(member)은 링크로 들어온다. 역할: 편집장(호스트) · 편집자 · 검토자.
- **담당마다 「명령할 수 있는 사람」 목록**을 둔다(`collab.json` — `seats.json` 은 원본 꼴을 건드리지 않는다). 편집장은 모든 담당.
- 권한 없는 사람의 요청칸은 「제안」 — 그 담당에 권한 있는 사람이 받아들이면 대기열로.

### 4.6 접속 — 줌처럼

| 길 | 설명 |
| - | - |
| 링크 | `https://<주소>/j/<토큰>` → 이름 입력 → 기기 쿠키(HttpOnly · SameSite=Strict) → 주소창에서 토큰 지움 |
| 공용 링크 | 여럿이, 이름은 스스로 밝힘, 기본 검토자 |
| 개인 링크 | 한 사람용, 이름 · 역할 고정 — 「누가 시켰나」가 확실 |
| 편집장 장치 | 대기실 · 회의 잠금 · 내보내기 · 만료 · 한 번만 쓰기 · 참가자 목록 |

| 바깥 길 | 주소 | 권장 |
| - | - | - |
| Cloudflare 이름 붙인 터널 | 내 도메인 고정, 여유 있음, 계정 + 도메인 필요 | 팀이 계속 쓸 때 |
| Tailscale Funnel | `https://<pc>.<tailnet>.ts.net` 고정, 대역폭 제한 | 처음 · 소규모 |
| Cloudflare quick tunnel | 매번 바뀜, 200 동시 · SSE 없음 | 시연만 |
| 없음 | LAN 주소, 사무실 안에서만 | 대체 |

IP · 네트워크 위치로 믿는 길은 없다. 모든 요청(슬라이드 · 글꼴 포함)은 쿠키나 토큰이 있어야 한다.

### 4.7 원격 대역폭 — 1Mbps 에서도

캐시(ETag · immutable) · 썸네일 PNG · Pretendard 나눠 받기(unicode-range) · gzip/brotli · 지금 쪽 먼저. 목표: Funnel 에서 첫 화면 10초 안.

### 4.8 보안 경계

원격 API 는 의도 허용 목록뿐(`abs_*` · root 를 받는 `fs_*` · `claude_path` · 설정 · 바깥 길 · 멤버 관리는 원격에 없음). 슬라이드 HTML CSP. 토큰 128비트 · 해시 · 실패 제한 · 감사 기록 · 바깥 열림 표시 · 자동 닫기. 편집 링크는 짧은 만료.

| 주간 · 월간 보고 취합 | 팀마다 담당 하나. 담당 세션이 지난주 맥락을 기억 → 「이번 주 숫자로」 한 줄. 판 목록에 누가 무엇을 바꿨는지 |
| 고객 실시간 리뷰 | 대기실 켠 보기 링크 → 고객이 표시 · 의견 → 담당이 바로 반영 |
| 강의 자료 공동 제작 · 리허설 | 장마다 담당 · 「따라가기」 |
| 바깥 Claude Code 와 섞어 쓰기 | 어떤 담당은 개발자가 터미널 Claude Code 로(원본 방식), 어떤 담당은 기획자가 브라우저로 — 같은 담당 창 · 같은 판 목록 |

## 9. 먼저 할 기술 검증 실험 (M1 첫 작업)

1. WebSocket 이 Tailscale Funnel · quick tunnel 을 통과하는가, 실제 덱 첫 화면 시간
2. `--safe-mode --setting-sources ""` + `--settings` 권한 규칙으로 Edit · Write 제한이 듣는가
3. 인증이 다른 두 턴이 `--resume` 으로 같은 세션에 이어지는가, 토큰 환경 변수 이름
4. `--session-id` 세션 jsonl 을 다른 작업 폴더 이름 아래로 복사해도 `--resume` 이 되는가
5. `asset_resolver()` 로 내장 화면을 axum 으로 내줄 수 있는가 (개발 · 배포)
6. 앱 담당 세션을 `presence.json` 에 적었을 때 원본 CLI(join · seats) · 담당 창이 깨지지 않는가
